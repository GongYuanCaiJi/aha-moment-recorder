# Triage Labels

Skills 使用五個 canonical triage roles。此檔案將這些 roles 對應至本 repo issue tracker 實際使用的 label 字串。

| `mattpocock/skills` 中的 label | Tracker 實際使用的 label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer 需要評估此 issue |
| `needs-info` | `needs-info` | 等待 reporter 補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格已完整，可交由 AFK agent 處理 |
| `ready-for-human` | `ready-for-human` | 需要由人類實作 |
| `wontfix` | `wontfix` | 不會採取行動 |

當 skill 提到某個 role（例如「套用 AFK-ready triage label」）時，使用此表中對應的 label 字串。

若實際使用的詞彙不同，可編輯右欄以符合既有 tracker 設定。
